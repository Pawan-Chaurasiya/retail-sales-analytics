# Retail Sales Analytics

## 📌 Project Overview
An end-to-end Retail Sales Analytics project focused on analyzing sales, profit, customers, products, discounts, and regional performance.

## 🎯 Objective
- Analyze overall sales and profitability
- Identify top-performing products and customers
- Analyze category and regional performance
- Understand the impact of discounts on profit
- Build an interactive Power BI dashboard

## 🛠️ Tools & Technologies
- Excel
- Python (Pandas, NumPy)
- MySQL
- Power BI
- DAX

## 🔄 Project Workflow
Excel → Python → MySQL → Power BI

## 📊 Key Analysis
- Sales & Profit Analysis
- Customer Analysis
- Product Analysis
- Category & Sub-Category Analysis
- Regional Analysis
- Discount vs Profit Analysis
- Outlier Analysis
- Correlation Analysis
- Customer Ranking

## 📈 Power BI Dashboard
Interactive dashboard containing:
- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Category Performance
- Regional Performance
- Monthly Sales & Profit Trend
- Top 10 Products
- Discount vs Profit
- Interactive Slicers
